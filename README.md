# Small Wise One

Production site for Small Wise One (Loretta Noble), served by GitHub Pages at https://smallwiseone.com.

1. Static HTML and CSS with relative links, served from the repository root (`index.html`, `portfolio/`, `collaboration/`, `about/`, `contact/`).
2. Shared styles, scripts, fonts and images live in `assets/`.
3. `CNAME` must stay `smallwiseone.com`.
4. Content was promoted from SmallWiseOneDesign/swo-demo on 2026-11-19. The previous site is preserved at tag `pre-swo-promotion-2026-11-19` and branch `legacy-site-2026-11-19`.

## Local preview

From the repository root run `python3 -m http.server 8000` and open http://localhost:8000/.
